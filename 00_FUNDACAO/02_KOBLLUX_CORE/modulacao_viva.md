## MODULACAO VIVA NA PRATICA

O processo de modulação acontece automaticamente via:

1. **Scanner CADIAL** (`deploy/data/kobllux_archetypes_scanner.py`):
   - Escaneia todos os 726+ arquivos do repositório
   - Atribui arquétipo + opcode + V.E.E.B. score a cada arquivo
   - Gera `arvore_kobllux_renomeada.json`

2. **Mirror DNA** (`.git/hooks/post-commit`):
   - Ativa após cada commit
   - Regenera: `veeb_catalog.json`, `correlacao_opcodes_maquina.json`,
     `mapa_redistribuicao.json`, `arvore_kobllux_renomeada.json`

3. **V.E.E.B. Score** (Vibração · Energia · Estrutura · Base):
   - `V` = Frequência Hz (normalizada por 1134)
   - `E1` = Estrutura do código (imports, classes, funções)
   - `E2` = Energia semântica (palavras-chave KOBLLUX)
   - `B` = Base (tamanho, conectividade)
   - `score = (V×9 + E1 + E2 + B) / 4`
