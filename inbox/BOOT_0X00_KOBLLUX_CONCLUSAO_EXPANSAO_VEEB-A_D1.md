## 6) Etymologias Essenciais (ultracurtas)

- **Expandir** < lat. *expandere* (desdobrar para fora) → dar espaço à forma.  
- **Síntese** < gr. *sýnthesis* (composição) → unir partes em um todo.  
- **Verdade** < lat. *veritas* → o que permanece.  
- **Integrar** < lat. *integer* (inteiro) → tornar inteiro novamente.  
- **Δ (delta)** < gr. letra delta → variação/desvio a superar.  
- **∴ (therefore)** sinal de conclusão → “logo”, selo do sentido.
