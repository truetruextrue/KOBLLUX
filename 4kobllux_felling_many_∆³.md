### **III. Termos Técnicos do ManyChat**

Estes são os componentes práticos para a implementação do sistema:

*   **Flow (Fluxo)**: Uma sequência automatizada de mensagens e ações que o bot executa.
*   **Trigger (Gatilho)**: O evento que inicia um "Flow" (ex: um novo seguidor, uma palavra-chave digitada, um clique em um botão).
*   **Condition (Condição)**: Um ponto no fluxo onde o sistema verifica se um critério específico é atendido (ex: se o usuário possui uma determinada "Tag") para decidir o próximo passo.
*   **Action (Ação)**: Uma instrução que o bot executa, como adicionar uma "Tag", definir um "Custom Field" ou direcionar para outro "Flow".
*   **Message Block (Bloco de Mensagem)**: Um conjunto de mensagens (A1-A5) que representam a comunicação de um arquétipo.
*   **Custom Fields (Campos Personalizados)**: Variáveis que armazenam informações específicas sobre cada usuário ou sobre o estado atual da interação (ex: `last_archetype` para registrar o último arquétipo acessado, `intencao_compra` para indicar o nível de interesse de compra).
*   **Tags**: Rótulos usados para categorizar usuários ou marcar eventos específicos (ex: `atlas_visto` para indicar que o usuário passou pelo fluxo ATLAS, `cliente_ativo` para identificar clientes).
*   **A1-A5**: Uma sequência padronizada de até cinco mensagens que compõem o conteúdo principal de cada arquétipo.

### **III. Termos Técnicos do ManyChat: As Ferramentas do DEV**

Estes são os componentes práticos que um desenvolvedor usa para *codificar* e *implantar* a experiência KOBLLUX.

*   **Flow (Fluxo)**: Uma **função** ou **método** que encapsula uma sequência de operações lógicas e de UI. `function handleWelcomeFlow() { ... }`
*   **Trigger (Gatilho)**: Um **listener de eventos** (`event listener`). `onUserFollow()`, `onKeywordMatch("NOVO")`, `onButtonClick("Oferta")`.
*   **Condition (Condição)**: Uma **instrução `if/else`** ou um **nó de decisão** no seu `flowchart`. `if (user.hasTag("atlas_visto")) { ... } else { ... }`
*   **Action (Ação)**: Uma **chamada de função** que modifica o estado do sistema ou do usuário. `user.addTag("atlas_visto")`, `user.setCustomField("last_archetype", "ATLAS")`, `navigateToFlow("03-VITALIS")`.
*   **Message Block (Bloco de Mensagem)**: Um **componente de UI/UX** que renderiza uma sequência de mensagens pré-definidas (A1-A5). Cada mensagem pode ter seu próprio `styling` (negrito, itálico).
*   **Custom Fields (Campos Personalizados)**: **Variáveis de estado** ou **atributos de objeto** associados a cada usuário. `user.last_archetype`, `user.intencao_compra`.
*   **Tags**: **Flags booleanas** ou **rótulos de categoria** para segmentação e controle de fluxo. `user.tags.includes("atlas_visto")`.
