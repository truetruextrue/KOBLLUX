## ② MIRROR DNA VIVO — Auto-Sync do Repositório

O **Mirror DNA** é o sistema de sincronização automática do repositório KOBLLUX. Ele garante que todos os catálogos estejam sempre atualizados e conexos com o fluxo vivo do repositório.

### Arquitetura do Mirror

```
git commit
    │
    ▼
.git/hooks/post-commit
    │
    ▼
kobllux_mirror_dna.py
    │
    ├── detecta arquivos mudados (git diff HEAD~1 HEAD)
    │
    ├── ativa gatilhos por script:
    │   ├── gerar_veeb_catalog.py      → veeb_catalog.json
    │   ├── gerar_correlacao_opcodes.py → correlacao_opcodes_maquina.json
    │   ├── gerar_mapa_redistribuicao.py → mapa_redistribuicao.json
    │   └── kobllux_archetypes_scanner.py → arvore_kobllux_renomeada.json
    │
    ├── gera KOBLLUX_MIRROR.sh (comandos shell auto-atualizados)
    │
    └── registra em mirror_dna_log.json
```

### Catálogos do Mirror DNA

| Script | Saída | Gatilho |
|--------|-------|---------|
| `gerar_veeb_catalog.py` | `veeb_catalog.json` | qualquer arquivo .py/.json/.md |
| `gerar_correlacao_opcodes.py` | `correlacao_opcodes_maquina.json` | arquivos opcode/correlacao |
| `gerar_mapa_redistribuicao.py` | `mapa_redistribuicao.json` | redistribuicao/codex-escritos |
| `kobllux_archetypes_scanner.py` | `arvore_kobllux_renomeada.json` | arquetipo/scanner |

### Comandos de Uso

```bash
# Sync incremental (detecta mudanças do último commit)
python3 deploy/data/kobllux_mirror_dna.py

# Sync total (todos os catálogos)
python3 deploy/data/kobllux_mirror_dna.py --full

# Instalar como git hook (auto-roda a cada commit)
python3 deploy/data/kobllux_mirror_dna.py --instalar-hook

# Ver status do mirror
python3 deploy/data/kobllux_mirror_dna.py --status

# Shell de sync rápido (gerado automaticamente)
bash deploy/data/KOBLLUX_MIRROR.sh
```
